LWD 论文导读
================================================================================

LWD 将机器人机群部署产生的成功、失败与人工纠正接入共享训练，用分布型隐式价值学习和伴随匹配，持续改进一个通用 VLA 策略。

这篇笔记重点梳理 DIVL 的分位数目标、QAM 的策略更新、离线到在线的数据混合，以及版本化 replay 系统；结合八个真机任务，区分成功率、步骤评分与机群运行指标。

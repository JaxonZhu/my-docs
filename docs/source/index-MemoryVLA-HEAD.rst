MemoryVLA 论文导读
================================================================================

有些操作在完成前后几乎没有视觉差异，比如按一下按钮。MemoryVLA 通过引入记忆，帮助模型判断已经做过什么，再生成后续动作。

我最关心记忆如何参与动作生成，以及训练时如何保持数据的时序连续性。正文重点拆解模型结构和 dataloader 设计，也整理了相关任务的评测。

GR-RL 论文导读
================================================================================

GR-RL 通过离线与在线强化学习对 VLA 进行后训练，挑战的是把鞋带穿进鞋孔这类长程精细操作。

我尤其关注其中能借鉴到实践的设计：轨迹增广、任务进度预测，以及如何训练基于流匹配的策略。正文顺着训练流程拆解这些方法，也整理了实验中的观察。

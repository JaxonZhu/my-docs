MemER 论文导读
================================================================================

MemER 从历史经验中检索关键帧，帮助机器人记住长程任务里已经发生的事。

我重点看了两部分：模型如何挑选值得保留的视觉记忆，以及实验如何评估记忆的作用。尤其是成功率之外的搜索路径、计数误差和分步评分，对设计自己的任务很有启发。

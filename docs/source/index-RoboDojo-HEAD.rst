RoboDojo 论文导读
================================================================================

RoboDojo 将仿真的规模化能力诊断与真机的物理部署测试连接起来，使用五类仿真任务、三种机器人本体，以及统一策略接口，评估通用操作模型在不同条件下的表现。

这篇笔记重点梳理任务与数据配置、异构并行仿真、真机场景复位、评分协议和 XPolicyLab 接口，结合报告中的固定实验结果，理解部分进展、最终成功与部署可靠性之间的差别。

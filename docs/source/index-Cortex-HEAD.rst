Cortex 论文导读
================================================================================

Cortex 通过规范化技能、子任务与语义记忆接口，连接高层 VLM 规划器和底层 VLA 执行器，并用事件均衡采样学习长程任务中的等待、完成判断与阶段切换。

这篇笔记介绍元数据构建、异步运行和部署约束，结合规划评分、仿真成功率与真实双臂实验，解释双向对齐的作用以及零样本迁移的适用范围。

Xiaomi-Robotics-0 论文阅读
================================================================================

Xiaomi-Robotics-0 将视觉语言模型与连续动作生成结合，通过两阶段预训练保留视觉语言能力，再用动作前缀、Lambda 注意力掩码和异步执行，让机器人在模型推理期间持续运动。

这篇笔记从模型结构、数学目标、数据和训练配置展开，重点分析动作连续性与反应性的取舍，并对照论文结果理解仿真表现、真机吞吐量和能力保留的边界。

EgoLive 论文导读
================================================================================

EgoLive 使用 JoyEgoCam 双目头戴设备，在真实作业环境中采集第一人称视频，并通过自动流程生成相机轨迹、三维手部关键点、深度、手物掩码和子任务描述。

这篇笔记围绕采集规格、手部与相机运动、双目优化和语义标注展开，结合数据分布、深度误差与描述案例，说明这些人类示范能够提供什么监督，以及论文验证的范围。

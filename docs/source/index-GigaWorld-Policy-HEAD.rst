GigaWorld-Policy 论文导读
================================================================================

GigaWorld-Policy 将未来视频作为训练时的辅助监督，通过分块因果注意力，让部署时的动作生成无需等待视频采样，在共享视频骨干上实现动作与视觉动态的联合学习。

这篇笔记重点解释掩码的信息流、视频损失如何影响动作表征，以及多阶段预训练的作用；同时核对推理延迟、真机评分与数据效率实验，区分原论文与后续 GWP-0.5 的发布范围。

Fast-WAM 阅读与源码分析
================================================================================

Fast-WAM 将训练时的视频监督与推理时的未来想象拆开研究。模型保留视频和动作联合训练，让动作只读取当前观测，再以单次视频编码和多步动作去噪降低部署延迟。

这篇笔记从注意力掩码、数据采样与缓存机制入手，核对仿真和真机实验的证据；同时区分预测长度与执行前缀，并说明后续加速实现和 Optional IDM 与原论文的不同。

DistRL 阅读与源码分析
================================================================================

DistRL 面向 Android 设备控制，把交互采集和策略训练拆成异步 Host-Worker 架构，减少不同任务耗时带来的等待，再用 A-RIDE 处理旧策略产生的数据。

我关注采集、回放和更新如何协作，以及论文设计与代码实现之间的差异。正文依次梳理系统架构、核心算法、训练流程和实验结果，结合代码阅读理解这些设计如何落地。

mimic-video 论文导读
================================================================================

mimic-video 尝试用预训练视频模型的表征来指导动作生成。我关注它能否减少机器人演示数据的需求。

一个值得细看的设计是：动作生成不必等到未来视频完全去噪。正文重点整理中间特征的提取方式、动作解码过程，以及样本效率和历史观测相关的实验。

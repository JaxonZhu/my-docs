EgoVLA 论文导读
================================================================================

EgoVLA 从带有三维手部标注的第一人称人类视频中学习动作，再通过统一的手腕与 MANO 表示，将机器人示范接入同一个模型，并把预测转换为机器人执行命令。

这篇笔记梳理数据混合、视觉历史、动作回归与 Rot6D 损失，展开双向重定向过程，再结合仿真 benchmark 的成功率和消融结果，讨论人类预训练的收益与机器人数据仍不可替代的原因。

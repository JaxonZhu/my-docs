TrAct 论文导读
================================================================================

TrAct 用视觉点轨迹连接机器人控制与未来视频预测：策略提出配对的动作和轨迹，世界模型生成候选未来，视觉语言评分模型选择最符合任务目标的结果，再执行对应动作。

这篇笔记梳理轨迹表示、联合训练目标与推理时动作选择，并对照 LIBERO-INTEGRAL 和真机结果，分析方法的收益、实验边界与复现所需的细节。

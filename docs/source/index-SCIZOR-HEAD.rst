SCIZOR 论文导读
================================================================================

SCIZOR 面向大规模模仿学习数据中的质量差异与重复问题，用自监督任务进度识别低质量片段，再根据状态与动作的联合表征去重，将筛选粒度细化到轨迹内部的训练样本。

这篇笔记重点梳理进度评分、时间折扣、轨迹分数混合与统一阈值，结合 OXE、RoboMimic 和 Sirius-Fleet 的实验，分析细粒度筛选的收益、误检与漏检，以及必要等待和恢复行为带来的挑战。

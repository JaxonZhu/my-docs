EgoMimic 论文导读
================================================================================

EgoMimic 使用 Project Aria 采集第一人称视频和三维手部轨迹，通过硬件设计、坐标变换、统计归一化与视觉掩码，让人类示范与机器人数据共同训练 ACT 风格策略。

这篇笔记展开共享位置预测与机器人关节控制的分工，解释人机动作窗口、联合损失和真实执行频率，再结合三个真实任务、场景迁移与消融实验，讨论人类数据扩展的收益与适用条件。

经验分析
================================================================================

这一类以研究问题和受控实验为主线，分析哪些因素带来收益、哪些现象有其他解释，以及结论能推广到什么范围。EgoWAM 比较人机迁移中的未来表征，Fast-WAM 讨论视频监督与推理时未来想象各自的作用，OpenWAM 研究世界动作模型的结构选择与预训练配方，RoboJEPA 则检验潜在世界模型的缩放规律与规划能力之间的关系。

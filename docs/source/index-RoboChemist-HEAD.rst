RoboChemist 论文导读
================================================================================

RoboChemist 面向长程化学实验，将视觉语言模型的规划与机器人执行结合起来，并在任务过程中检查与纠正。

我关注它怎样把一项复杂实验拆成可执行的步骤，以及执行遇到问题时如何调整。正文顺着双循环框架展开，也整理了作者讨论的局限。

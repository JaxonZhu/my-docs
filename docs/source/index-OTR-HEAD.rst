OTR 论文导读
================================================================================

OTR 用少量专家演示，为没有奖励标签的离线轨迹标注奖励。方法围绕最优传输展开，是我研究奖励重标注时读的一篇基础工作。

正文重点拆解轨迹如何匹配、距离如何转成奖励，以及实验怎样验证这些奖励。读完后，可以继续看 :doc:`AILOT <index-AILOT-HEAD>` 如何改进用于匹配的表征。

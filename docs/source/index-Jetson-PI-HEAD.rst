Jetson-PI 论文与源码解读
================================================================================

Jetson-PI 面向端侧 VLA 的长推理延迟，通过未来表征修正、置信度调度和系统加速，改善异步执行中的观测错位与动作更新速度。官方算法仓库现已更名为 EagleVLA，这里沿用原论文名称。

这篇笔记重点梳理未来修正与 KV 缓存的接口，区分论文训练方法和公开代码流程，并对照 LIBERO、Orin 延迟与真机衣物整理实验，理解结果的适用范围。

# TrAct 论文解读：用视觉轨迹连接动作与世界模型

论文原题：TrAct: Bridging Robot Control and Visual Prediction with Visual Tracks

- 作者：Zhi Cao、Howard Ji、Kevin Zhang、Kuangzhi Ge、Li Fei-Fei、Jiajun Wu、Huang Huang
- 机构：University of Michigan、Stanford University
- 发表：arXiv，2026
- 论文：[arXiv:2608.24101v3](https://arxiv.org/abs/2608.24101v3)（2026 年 9 月 1 日修订）
- 项目：[TrAct 官方项目页](https://lol-png.github.io/tract/)

TrAct 让策略同时提出机器人动作和二维视觉点轨迹，再用轨迹条件世界模型预测未来视频，通过视觉语言评分选出要执行的动作。这篇笔记关注共享轨迹表示如何连接控制与预测，以及视频质量、动作选择收益和实际部署之间还有哪些证据缺口。

阅读依据为论文 v3，共 22 页，包含正文与附录 A–G。文中的“论文事实”指原文报告，“作者解释”指论文对结果的解释，“分析判断”指个人理解或对证据边界的讨论。“未报告”仅限定于这一版 PDF，不用基础模型的默认配置补齐。页码沿用该 PDF，pp 表示百分点，汇总数值优先保留原表的舍入口径。

## 一、论文要解决什么问题？

- **论文试图解决的具体问题**：低维、依赖机器人本体的动作向量，<u>不容易直接约束图像中的精细变化</u>；动作条件世界模型可能<u>预测出错误的夹爪姿态、物体运动和跨视角关系</u>，进而误导候选动作选择。
- **作者希望读者相信的核心主张**：以视觉点轨迹作为策略与世界模型共享的**接口**，可以改善未来视频预测，并提高基于预测结果的动作选择效果。
- **核心交付物**：由 VLAT、TWM 和 VLAC 构成的 TrAct 方法；附带 LIBERO-INTEGRAL 的 20 个泛化任务设置。
- **一句话研究思路**：让策略同时提出 “怎么动” 和 “画面中的点会怎么动” ；世界模型据后者生成未来，奖励模型选出最符合指令的未来，机器人执行与其配对的动作。
- **最强证据**：使用 VLAT 提案的对照中，TWM 选择相对 AWM 选择，将 LIBERO-INTEGRAL 汇总成功率<u>从 49% 提高到 55%</u>，真机<u>从 66% 提高到 76%</u>；<u>三次仿真评测种子</u>下结果仍保持优势。
- **最大局限**：决策依赖 “预测轨迹与配对动作实际后果一致” 这一关键链路，但没有直接的一致性误差审计；此外，ControlNet 与动作 cross-attention 的结构差异、奖励模型误差和推理成本仍限制因果归因与部署判断。

### 2.6 评估设置

- **标准 LIBERO**：4 个 suite，每个 10 个任务，每任务 10 次 rollout，即每 suite 100 次；用于检查常规任务性能。
- **LIBERO-INTEGRAL**：20 个任务；10 个鲁棒性任务，覆盖 Swap、Object、Task、Camera、RobotInit 五类，每类 2 个；另有 10 个 UR5 跨 embodiment 任务。每任务 10 次 rollout，即每种方法每个评测种子 200 次。
- **真机**：<u>5 个测试任务，每个在训练背景 R 和不同背景 D 下测试</u>。原文写 “每任务 10 个 episodes” ，表4按任务与背景分行报告。按每个 "任务-背景" 设置 10 次理解，则每策略 100 次；但正文没有进一步澄清是否每个背景各 10 次，复现时应确认。

- **视频预测**：仿真使用来自 LIBERO-INTEGRAL 评测任务的 100 个生成视频；真机使用评测 rollout 的 100 个生成视频，均评价两个相机视角。
- **随机种子**：仿真主表使用单个 evaluation seed；对 VLAT+AWM 与 TrAct 用固定 checkpoints、候选数与选择超参数，重测 3 个独立评测种子。
- **ID / OOD 与微调**：先使用目标实验体系的数据微调，再测试相应分布变化。真机“未见任务”包括已训练技能的物体或初始状态变化；**不能概括成完全未见技能**，也不能概括成无目标域数据的 zero-shot。UR5 是否出现于 2K 微调 episodes、动作如何适配，原文未详细交代。

## 三、核心主张与成立条件

### 3.1 从共享视觉表示到真实控制

**作者解释**：（1）相比机器人动作，二维视觉点轨迹更接近图像变化的空间结构，也更容易跨机器人共享。（2）用同一策略联合预测<u>动作和轨迹</u>，再让世界模型根据轨迹生成可评价的视觉未来，可以提高动作选择质量。

**分析判断**：这条主张要对实际控制成立，至少需要四个条件：

1. **候选覆盖**：VLAT 采样集合内存在较好的可执行动作，且 TSR 没有只制造无效多样性。
2. **动作与轨迹一致**：$a_i$ 执行后产生的真实视觉运动，与其配对的 $\tau_i$ 相符。
3. **预测遵从且可信**：TWM 既遵从轨迹，又不过度补出没有发生的接触或成功。
4. **奖励排序可靠**：VLAC 对预测视频的排序，与真实执行后的任务完成程度大体一致。

只证明视频看起来更接近参考，不足以分别证明上述四个条件；任务成功率提供了整体证据，但没有把每个误差环节拆开。

### 3.2 提案、预测、评分与执行

::::{tip}
**一次决策的主线**：当前观测与语言 → VLAT 采样 $K$ 组动作—轨迹对 → TWM 根据各组轨迹预测视频 → VLAC 按指令评分 → 选择最高分索引 → 执行对应的完整 16 步动作 → 获取新观测并重复。

这三个模块分别承担提案、预测和评价；后面的执行步骤始终使用与轨迹配对的动作。
::::

- VLAC 的显式评分输入是预测视频和语言。
- **机器人执行的是原先配对的动作，并没有在视频生成后再从视频求逆动力学动作。**

### 3.3 与相关方法的区别

| 比较对象 | TrAct 增加或改变了什么 | 阅读边界 |
|:-:|:-:|:-:|
| $\pi_{0.5}$ | 增加轨迹预测监督与输出，并在完整 TrAct 中增加视频预测、评分和候选选择。 | $\pi_{0.5}$ → TrAct 同时改变多项因素，不能把全部差值归给 TWM。 |
| VLAT，无动作选择 | 用 TWM 和 VLAC 对同一类策略提案进行预测式排序。 | 这项对照支持完整选择流程的效用，包含额外推理计算。 |
| VLAT+AWM | 将动作条件预测改成轨迹条件预测；两者都采用多视角 SVD 世界模型。 | 这是最接近核心接口主张的对照，但条件注入结构也发生变化。 |
| 既有轨迹 / flow 方法 | 原文相关工作将轨迹用于动作生成或世界模型条件化；TrAct 强调把轨迹生成的视觉未来交给语言奖励模型评价，再选配对动作。 | 这是 TrAct 作者在 §2 的定位；本文未独立复核所有前作，不能据此宣称“首次”。 |
| VLAC | 复用其视觉语言评价思路，把评分对象接到 TWM 预测结果上。 | 没有继承引用论文中的所有 RL 训练流程；本篇的实际算法需单独阅读。 |

### 4.2 动作条件世界模型的失败模式

论文针对的是**动作条件与像素运动之间的弱对应关系**：同样或相近的机器人命令，在不同几何、物体和接触条件下会产生不同视觉变化；世界模型需要从稀疏命令恢复丰富的视觉后果。

```{figure} images/TrAct/tract-video-prediction.png
:alt: 动作条件世界模型与轨迹条件世界模型在两个相机视角中的视频预测对比
:width: 100%
:align: center

**原论文图 3：未来视频预测对比**。图中比较 AWM 与 TWM 的预测；重点观察夹爪姿态、物体运动和不同视角之间的一致性。
```

图3和图5给出的失败现象包括：夹爪姿态错误、背景物体消失、跨视角物体位置不匹配、物体形状失真、机械臂转动或平移错误。

**分析判断**：这些失败与几类常见问题的关系如下：

- **compounding error**：通过每个 chunk 后重新观测缓解长时间开环执行，但没有**专门量化**误差累积或恢复能力。
- **sparse reward**：使用学习到的「视觉语言评分模型」帮助排序；没有提出新的<u>稀疏奖励 RL 优化目标</u>。
- **critic instability / credit assignment**：没有 TD critic 或 action-chunk Bellman 更新，因此不是这类训练稳定性论文。
- **inference latency**：<u>多候选视频生成增加推理成本</u>；论文只展示候选数量与成功率的权衡，未证明降低延迟。

#### 轨迹表示：人类视频究竟监督什么

轨迹 slot 是**固定的 view-specific token 索引**，不是通过对象发现学习出来的 object slot。某数据没有对应视角、手或动作维度时，用二值 mask 在 attention 和 loss 中屏蔽。

| 数据 / 视角 | 激活的轨迹点 | 动作监督 |
|---|---|---|
| DROID，agent-view | 每个该类视角 7 个夹爪关联点 | 有机器人动作标签，监督动作与轨迹。 |
| DROID，wrist-view | 7 个夹爪关联点 + 25 个均匀网格场景点 | 同上。 |
| EgoDex，单个 egocentric view | 14 个手关联点，每只手 7 个；另加 25 个背景点 | **仅轨迹监督，不把人手运动当作机器人动作标签。** |
| BridgeData V2，附录扩展模型 | 文中描述采用同样的 slot 分配与 masking | 有机器人动作监督；原文称因缺少相机外参，直接从图像使用 CoTracker 获取轨迹。 |

主流程中的机器人夹爪点由 7 个固定三维偏移、机器人位姿和相机标定投影得到；场景点从 $5\times5$ 网格初始化并用 CoTracker 跟踪。EgoDex 手点的具体选点与投影过程没有同等详细的描述。（来源：论文 §3.2、§4.1；附录B）

**分析判断**：外部视角重点监督末端运动；腕部视角还需要背景点提供相机运动参照。这使表示在不同数据间可共享，但二维点仍依赖视角和成像几何，“embodiment-agnostic”不意味着几何上完全不变，也不意味着动作空间已统一。

附录 B 给出的 token 构造为：

```{math}
z_{t,v,i}=\varphi(\tau_{t,v,i})+e_{\mathrm{view}}(v)+e_{\mathrm{slot}}(i)+e_{\mathrm{time}}(t).
```

其中 $\varphi$ 编码轨迹坐标，三个 embedding 分别区分视角、slot 和时间。此式沿用附录的坐标编码含义；它不是世界模型参数 $\phi$。原文明说**不使用 embodiment-specific embedding**。

### 4.4 训练目标与候选选择目标

#### 策略目标（论文式 2）

```{math}
\mathcal L_{\mathrm{VLAT}}
=\mathcal L_{\mathrm{flow}}(a,a^*)
+\lambda\mathcal L_{\mathrm{flow}}(\tau,\tau^*).
```

动作项以机器人示范动作为标签；轨迹项以提取的视觉轨迹为标签。前者学习可执行动作，后者学习与场景运动相关的预测表示。

附录进一步给出处理人类与机器人混合数据的目标：

```{math}
\mathcal L=\mathcal L_{\mathrm{track}}
+\mathbb 1_{\mathrm{robot}}\mathcal L_{\mathrm{action}}.
```

**分析判断**：两式分别强调动作-轨迹联合学习和缺失动作监督的屏蔽，并不意味着附录建立了新 RL 损失。附录未再显式写 $\lambda$，其与主文加权、不同 slot 数的归一化如何对应，仍需实现确认。

| 目标 / 梯度项目 | 原文信息与缺口 |
|---|---|
| Flow matching 的完整展开 | **未报告**噪声插值路径、时间采样分布、velocity target、归一化、$\lambda$ 数值及对 action / track 的精确权重。仅凭式(2)不能恢复可运行的完整 loss。 |
| TWM / AWM loss | 明确采用 SVD、预训练和微调；**未报告**本篇实现的扩散目标公式、预测参数化、噪声日程及辅助损失。不能把 SVD 的常见公式写成本篇已明确采用的配置。 |
| VLAC loss | 仿真微调用预测 rollouts 和任务完成奖励；**未报告**标签到 0-50 分的映射、回归/分类/排序目标、失败数据配比及帧采样。 |
| stop-gradient / target network | 没有报告 target network、TD target 或特定 stop-gradient 结构。 |
| 梯度流向 | 在目标层面，动作和轨迹项监督 VLAT，视频目标用于世界模型，评分目标用于 VLAC；**未报告**各预训练子模块具体 trainable mask 和共享层梯度。 |
| 端到端奖励反传 | 推理式使用 $\arg\max$ 选索引；没有报告把 $R_\psi$ 的梯度经 TWM 反传到 VLAT 的训练方案。 |

#### 推理目标

```{math}
\begin{aligned}
\{(a_i,\tau_i)\}_{i=1}^{K}&\leftarrow\pi_\theta(o_t,l),\\
\hat v_i&=p_\phi(o_t,\tau_i),\\
i^*&=\arg\max_{i\in\{1,\ldots,K\}}R_\psi(\hat v_i,l).
\end{aligned}
```

最后执行 $a_{i^*}$。这是对**有限候选集合的评分最大化**，既没有宣称求得连续动作空间的全局最优解，也没有给出沿世界模型梯度优化动作的过程。

### 4.5 离线训练与一次完整决策

理解 TrAct 时，需要区分**离线模块训练**与**部署时决策循环**：前者更新模型参数，后者在有限候选中选择动作。算法 1 的循环本身没有 actor-critic 参数更新。

#### 各模块的训练流程

1. **从哪里采样什么数据？** VLAT 主预训练从 DROID 与 EgoDex 按 1:2 混合采样；机器人样本含观测、动作和提取的轨迹，人类样本提供观测与手/场景轨迹。微调换成 LIBERO 或自采真机示范。**未报告**精确窗口采样和语言字段处理。
2. **如何计算 target？** 动作 target 来自有效的机器人标签；<u>track target 来自投影或跟踪</u>。根据视角、slot 和动作维度构造 mask。**未报告** flow velocity target 的具体构造；这里不存在已定义的 Bellman target。
3. **如何更新 critic / reward model？** VLAC 作为单独组件微调；仿真使用预测 rollouts 与任务完成奖励，5K 步、batch 16；真机 4K 步、batch 16。原文没有报告它与 VLAT 每步交替更新，也没有完整监督目标。
4. **如何生成或选择动作？** 训练策略依照联合 flow-matching 目标学习；候选评分与选择属于下一小节的推理过程。原文未报告<u>把 reranking 胜出的动作当作伪标签回训策略</u>。
5. **如何更新 actor / VLA？** 在可训练参数上优化动作和轨迹监督目标。EgoDex 屏蔽动作 loss，机器人样本同时监督两项；不能据此断言所有 backbone 参数都被更新。
6. **真机 rollout、reset 和训练如何交替？** 描述为先采集示范、训练各模块，再进行任务评测；未报告在线 rollout 回流训练、自动 reset 或训练-部署交替日程。

**一次 VLAT 更新的可确认概括**：读取一个训练 batch，为有效动作和轨迹构造监督与 mask，计算联合 flow-matching 损失，更新策略中允许训练的参数。**具体噪声目标、优化器和参数冻结范围缺失，故这是一份受原文约束的算法说明，不能冒充完整复现配方。**

世界模型另以视频数据和对应条件训练，奖励模型另以结果评分监督微调。论文按组件报告训练阶段；未给出统一联合优化三者的损失。

#### 一次完整的 TrAct 推理循环

1. 获取当前观测 $o_t$ 和任务指令 $l$。
2. VLAT 采用增大初始噪声与 TSR 的采样方式，提出 $K$ 组 $(a_i,\tau_i)$。
3. 对每组轨迹按视角形成空间控制图；agent-view 轨迹用红色通道，wrist-view 用蓝色通道；ControlNet 将条件送入 SVD 世界模型。
4. TWM 对每组候选生成未来视频 $\hat v_i$。
5. VLAC 给每段预测结果评分 $s_i=R_\psi(\hat v_i,l)$。
6. 选择最高分索引，取出与其轨迹配对的动作 $a_{i^*}$。
7. 执行完整 16 步动作，重新观测 $o_{t+H}$，继续循环；循环中没有反向传播或参数更新。

| 推理超参数 | 仿真 | 真机 |
|:-:|:--:|:--:|
| 动作与轨迹 horizon $H$ | 16 | 16 |
| 候选数 $K$ | 20 | 16 |
| 初始 noise scale | 2 | 2 |
| TSR k-value | 3 | 4 |

### 4.6 方法依赖的前提

| 关键前提 | 本文的依赖与证据边界 |
|---|---|
| reward 是否可靠？ | VLAC 需在生成视频上正确区分进展。没有独立报告排序准确率、校准误差或对世界模型幻觉的敏感性。 |
| action chunk 是否作为宏动作？ | 每次对整段候选进行评价并执行完整 16 步，可以视为决策层的块状候选；**没有**定义半马尔可夫宏动作 Bellman 方程。 |
| critic 能否评价 OOD action？ | VLAC 显式评价视觉结果，而非直接输入 OOD 动作的 Q 函数。泛化成功率提供间接支持，未分离评价器本身的 OOD 能力。 |
| 是否依赖 world model / 候选采样？ | 完整 TrAct 依赖 TWM、VLAC 和多候选 VLAT；去掉选择流程对应 VLAT 基线。 |
| 配对是否一致？ | 联合预测提供学习上的关联，但没有报告约束 $a_i$ 实际执行后必须实现 $\tau_i$ 的显式一致性 loss 或物理可行性验证。 |
| 轨迹能否承载充分信息？ | 夹爪点与稀疏网格提供空间指导；深度、遮挡、接触和非刚性形变仍可能存在歧义。原文未对这些因素分别消融。 |

上表中的未验证前提属于**分析判断**，不是作者给出的形式化保证。二维轨迹使视觉预测更容易，并不自动保证其对应动作在真实物理中可行。

### 4.7 计算成本与稳定性

**训练成本**已列于第 2 节。**未报告**每步实际 forward/backward 次数、训练墙钟时长、峰值显存、优化器、学习率、梯度裁剪和完整超参数敏感性。

**分析判断**：一次决策需要为 $K$ 个候选做视频预测和评分。用抽象串行成本表示：

```{math}
C_{\mathrm{decision}}(K)
\approx C_{\mathrm{proposal}}(K)
+K\,C_{\mathrm{world\ model}}
+K\,C_{\mathrm{score}}.
```

这是计算工作量的解释式，**不是论文实测时延**。候选可批处理时，墙钟时间还受显存、并行度和采样步数影响；原文没有给出具体部署实现。

- **是否穿过多步 diffusion / flow 反传？** 原文没有报告沿 “VLAC → TWM → VLAT” 采样链进行奖励反传；不能把推理链误读为可微规划训练。各模块自身采样与训练开销仍需代码确认。
- **候选数敏感性**：固定策略、世界模型和 critic，$K=5,10,20$ 的仿真成功率为 52%、54%、55%，边际收益递减。
- **统计稳定性**：三次 evaluation seeds 的比较支持固定 checkpoint 下的效果复现；未覆盖不同训练种子、不同奖励模型种子和不同数据子集。
- **没有实时性结论**：论文未报告单次生成/评分时延或端到端吞吐。候选数从 20 降至 5 的任务收益变化，并不能单独证明达到实时控制要求。

## 五、实验结果与因果解释

### 5.1 基线分别隔离了什么

| 方法 | 策略 | 用于选择的额外组件 | 主要比较意义 |
|---|---|---|---|
| $\pi_{0.5}$ | vanilla $\pi_{0.5}$ | 无 | 完整改进的起点。 |
| VLAT | 动作与轨迹联合预测 | 无 | 检验加入轨迹学习及对应训练方案后的策略能力。 |
| VLAT+AWM | VLAT | 动作条件视频预测 + VLAC 选择 | 检验预测式动作选择。 |
| TrAct | VLAT | 轨迹条件视频预测 + VLAC 选择 | 与上一行比较世界模型条件接口。 |
| $\pi_{0.5}$+VLAC，仅真机表 | $\pi_{0.5}$ | VLAC 候选选择 | 检验在原策略上加入选择的收益；原文没有与另外两种选择器同样详细地写出此基线的 rollout 接线。 |

**已控制的因素**：TWM 与 AWM 都以 SVD 为骨干，预训练同用 DROID、同为 30K 步/batch 64，微调使用相同下游数据、同为 25K 步/batch 16；二者都有多视角条件。

**未充分控制或交代的因素**：

- TWM 使用 ControlNet 空间控制，而 AWM 使用 MLP、view embedding 与 cross-attention。条件信息与注入结构共同改变，没有参数量和 FLOPs 匹配结果。
- $\pi_{0.5}$ 与 VLAT 的全部前置预训练预算未被逐项对齐说明。VLAT 额外使用 DROID+EgoDex；$\pi_{0.5}$ 基线是否接受等价新增训练没有清楚交代，因此“轨迹监督单独带来 17 pp”不是严格因果结论。
- 没有跨其他 VLA backbone 验证；没有系统对比多个 action-conditioned world model 的最佳结构或统一调参预算。
- 部署算法写明使用**预测**轨迹；视频表1究竟用预测轨迹还是 ground-truth 轨迹作为测试条件，没有明确区分。不能据表1自动得出纯预测轨迹条件下的全部精度结论。
- 没有 oracle scorer、真实执行结果排序、动作-轨迹错配或相同候选随机选择等消融，用于拆分提案、预测和评分的贡献。

以上为**分析判断**。最稳妥的解释是：报告的整体方案和该具体 TWM 实现有效；对单一机制的独立因果证明仍不完整。

## 七、实验有效性与复现边界

### 7.1 训练测试划分与 OOD 定义

**论文事实**：作者明确区分真机训练任务与测试变化，并用 LIBERO-INTEGRAL 定义鲁棒性与 UR5 测试。

**分析判断**：现有文字不足以完成独立泄漏审计：2K LIBERO episodes 的精确组成、与 PRO/Plus 任务变化的对应、UR5 数据是否完全排除于微调、世界模型及 reward model 的 train/validation/test 划分均未详列。大规模预训练数据是否与测试物体或任务语义重合也没有专门审计。正确结论是“无法独立排除”，而不是“已经发现泄漏”。

真机 R 只表示背景来自训练分布，不表示任务完全 ID；D 同时有任务变化与背景变化。研究“纯背景鲁棒性”时应保留这个条件。

### 7.2 基线的数据、算力与调参预算

**较公平的局部比较**：TWM 与 AWM 的数据和训练步数较明确地匹配；AWM 也有相机视角 embedding，不能把它写成缺乏多视角条件的弱基线。

**剩余缺口**：总参数量、ControlNet 与 cross-attention 的容量、总 FLOPs、端到端时延、奖励模型在两套世界模型间的具体复用或分别训练方式、全部调参次数未报告。$\pi_{0.5}$ 与 VLAT 的新增预训练是否完全等价也不清楚。

### 7.3 可以推广到什么范围

**可以支持的范围**：$\pi_{0.5}$ 系 VLAT；基于 SVD 的两个特定世界模型实现；LIBERO 标准套件及选取的 20 个变化任务；Franka 真机桌面操作及 5 个测试变化；UR5 仿真迁移。（来源：论文 §3-5；附录F）

**尚不能支持的范围**：任意机器人直接迁移、双臂或灵巧手控制、移动操作、高速动态交互、长时间自动恢复、接触力精确控制、开放环境长期部署，以及所有 VLA backbone 上都能获得同等增益。

### 7.4 最难复现的三个细节

1. **动作与轨迹数据契约**：动作维度、空间、单位、绝对/增量、归一化、时间对齐；7 个夹爪点的偏移值；不同数据的相机/slot 映射、遮挡mask、EgoDex手点提取和UR5动作适配。
2. **训练与梯度配方**：联合flow目标的插值和权重；Action/Track Head的cross-attention实现与冻结范围；SVD/ControlNet的训练方式；VLAC预测视频、奖励标签及完整loss如何配对。
3. **推理与评价契约**：TSR k-value的实际含义、采样步数、多视角视频打包、VLAC帧选择、是否等待视频生成、候选batch方式，以及成功判据、timeout、reset和每背景评测次数。

这些缺口不否定报告结果，但意味着本文目前提供的是可解释的方法设计，尚不足以从 PDF 单独恢复全部工程配置。


## 八、如何理解 TrAct 的贡献

**分析判断**：该方法主要改善的是 **inference-time action selection**：以结构化视觉运动连接可执行动作和可评价的未来。联合轨迹学习同时改善了所测策略的泛化，但没有提出新的 value estimation、Bellman credit assignment 或在线 exploration 更新规则。

- **证据较强的结论**：在本篇的 $\pi_{0.5}$、SVD、VLAC 组合与实验设置下，TWM 预测质量优于其 AWM 实现，完整选择方案在较难泛化任务上取得更高成功率。
- **证据尚不充分的结论**：收益完全来自轨迹表示、已统一所有 embodiment、奖励模型对失败未来可靠、能实时运行，或可以替代真实物理验证。
- **复用价值**：值得采用的是动作与视觉后果的成对接口及其受控评测思路。能否直接部署，还要补足动作 schema、标签生成、评分训练与时延配置。

RL Token 论文导读
================================================================================

RL Token 将 VLA 的内部表征与参考动作提供给轻量 actor–critic，在冻结大模型的在线阶段，用真机强化学习改进精密操作的成功率与速度。

这篇笔记重点梳理重建式 token、动作块 TD、参考动作约束和人工接管，结合四个任务理解关键阶段训练的效率来源，并区分有效数据时长、完整任务表现与自动切换的证据范围。

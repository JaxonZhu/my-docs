多数据集训练笔记
================================================================================

多任务模仿学习常把不同机器人、任务和采集条件下的演示混在一起。样本量差异会影响训练机会，数据集等权、样本等权与任务等权也对应不同目标。

这篇笔记用大、小两个数据源解释采样占比与单样本曝光的区别，整理幂次采样、质量与多样性权重，以及训练监控和评估方法，并对照论文说明具体策略的适用条件。

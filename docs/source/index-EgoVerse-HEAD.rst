EgoVerse 论文导读
================================================================================

EgoVerse 将学术实验室、产业伙伴与个人采集的第一人称操作数据接入共同平台，通过统一处理、数据索引和训练接口，支持持续扩展的人类数据研究。

这篇笔记梳理 EgoVerse-A 与 EgoVerse-I 的采集和标注、EgoDB 的数据访问设计、跨构形 Flow Matching 策略，并结合三种机器人平台与受控多样性实验，讨论数据对齐、规模和场景覆盖各自的作用。

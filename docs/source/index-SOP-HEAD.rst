SOP 论文导读
================================================================================

SOP 将真实机器人群的执行、人工纠错、云端学习与权重回传连接成持续闭环，让共享 VLA 在部署过程中适应任务中的失败状态，并支持 HG-DAgger、RECAP 等后训练算法。

这篇笔记重点梳理分布式数据流、任务均衡与在线／离线自适应采样，以及 episode 边界上的模型切换；结合三类真机任务，分析成功率、吞吐量与扩容加速的证据边界。

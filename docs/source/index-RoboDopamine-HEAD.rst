Robo-Dopamine 论文导读
================================================================================

Robo-Dopamine 研究如何从视觉中估计任务进度，并把它转成可用于强化学习的过程奖励。

读这篇时，我碰到了自己做奖励建模时也遇到的问题。正文重点看进度标注、奖励塑形，以及为什么“看起来有进展”仍可能让策略停在未完成任务的状态。

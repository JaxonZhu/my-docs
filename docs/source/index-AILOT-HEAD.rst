AILOT 论文导读
================================================================================

没有奖励标签的轨迹，能否借助少量专家演示重新标注奖励？AILOT 延续了 :doc:`OTR <OTR-paper>` 的思路，重点在于学习用于轨迹对齐的意图表征。

我更关心方法能否借鉴，所以正文主要拆解 successor features 如何构建意图表征，以及它与 :doc:`OTR <OTR-paper>` 的状态距离有何不同。D4RL 的分数对比没有展开。

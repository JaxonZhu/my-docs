EPIC-KITCHENS 论文导读
================================================================================

EPIC-KITCHENS 从真实家庭厨房采集第一人称长视频，通过参与者事后口述、众包时间定位和交互物体框标注，将自然活动整理为可以训练与评测的数据集。

这篇笔记聚焦 2018 年原始论文，梳理采集协议、多人标注融合、词汇归并和质量检查，再解释 seen 与 unseen 划分及三个基准任务，并讨论这些流程对今天数据建设的启发。

DiT4DiT 论文导读
================================================================================

DiT4DiT 利用视频模型的中间特征来生成动作。我是在读完 :doc:`mimic-video <mimic-video-paper>` 后接着读这篇的，两篇都关注视频表征对机器人控制的帮助。

值得对照着看的是：为什么不必生成清晰的未来视频，以及哪个去噪阶段的特征更适合动作解码。正文围绕模型设计和实验展开。

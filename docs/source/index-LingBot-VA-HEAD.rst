LingBot-VA 论文导读
================================================================================

LingBot-VA 将视频预测与动作生成放进一个自回归闭环，借助双流 MoT、KV-cache 和真实环境反馈，把视频世界模型用于机器人控制。

这篇笔记重点解释视觉动力学、逆动力学和异步 FDM 的条件关系，梳理部分去噪与训练配置，并分别阅读真机成功率、进度分数、样本效率和记忆实验。
